# StrokePoint++ figure plan

The artwork describes the implemented frozen PointNet++-derived application and the reviewed comparisons. It does not claim an optimal-transport mechanism, a new validated PointNet++ architecture, clinical stroke prediction, or NC/NMI acceptance.

## Visual references

- User-supplied RetinaFuse `figures.pptx`: 16 portrait slides, approximately 180 x 270 mm, Arial, open white space, compact panel letters, blue/burgundy/teal/ochre semantic colors, real input images above precise data panels. The source remains unchanged. Inspection previews remain private and are not redistributed.
- Dai, Yi et al., 3d-OT, Nature Methods 23, 760-771 (2026), DOI 10.1038/s41592-026-03034-9: object-to-representation-to-task visual narrative and explicit encoder views. Its spatial-omics alignment, SCOT, Sinkhorn, Chamfer and divergence objectives are not implemented by StrokePoint++ and must not appear as current-model modules.
- User-specified `nrc-scientific-figures` skill: editable vectors for scientific connections/equations/data, original layouts, English artwork and legends, final-size visual inspection.

## Main figures

1. **Study and implemented framework**. Real MRA crop and vessel surface, corresponding point cloud, model branches, frozen backbone versus fitted presence heads, deployment and protected roles. Evidence: descriptive real-data illustration and source-verified architecture.
2. **PointNet++ representation and candidate-level decision**. Hierarchical local/global/context pathways, actual tensor dimensions and frozen F/L readouts, DBSCAN candidate aggregation, mean/max descriptor, serialized logistic head, blocked-class reassignment. Equations denote implemented operations, not inferred mechanistic novelty.
3. **Development and original internal application validation**. Clean-development structural/embedding comparisons and original Y/Z internal aggregate results, with patient/scan denominators separated. Historical contaminated variants never support a positive claim. Original CT/MR deployment and reconstructed single-MRA deployment remain distinct.
4. **Locked external comparison**. Lausanne DEV and IXI-HH FINAL shown separately, paired contrasts and honest strong3D/Fuse/YZ ranking, plus a real, deterministic DEV illustration. No pooling, model selection, FINAL tuning or additional inference.
5. **Rare-vessel performance and correction safety**. Full-mask support denominators, Pcom/Acom/third-A2 recalls, gate correction versus newly introduced errors, sparse-support uncertainty and the unchanged patient-event safety boundary.

## Rendering and release

Final width: 180 mm. Target labels 7.5-9 pt, panel letters 11 pt. Match the reference's Arial and restrained blue/burgundy palette, while allowing sufficient height for legibility. Rasterize only true 3D/image data layers; keep text, equations, axes and scientific connections editable. Each main/Extended/supplementary figure has SVG, vector-text PDF and PNG; complete pages also appear in a combined inspection PDF. Labels name point-based Dice and native-presence FPR explicitly.

Real-data illustrations use only already evaluated development cases selected by their frozen manifest order, not by outcome. No raw subject arrays, identifiers, weights or source reference slides are included in the public code ZIP. Research-only local provenance is kept outside the public bundle. No training, model forward, new parameter search, protected-65 access or Y/Z overwrite is authorized by figure production.
